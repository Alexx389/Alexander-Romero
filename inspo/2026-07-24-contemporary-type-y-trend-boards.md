## Análisis
### Lo que funciona
- **Tipografía protagonista:** grande, bold, segura; con itálica de acento y motion (variable,
  reveal, desenfoque, rotación). Es el 80% del carácter.
- **Alto contraste puro:** negro inmersivo o blanco editorial, sin grises tibios en el medio.
- **Un solo acento cálido (naranja):** ordena toda la interacción sin ensuciar.
- **Atmósfera aurora holográfica** usada con criterio (momentos hero), no en todo.
- **Estructura editorial numerada** + mockups de dispositivos para presentar con nivel.

### Lo que se puede mejorar / dudas
- Definir si el mundo base es **negro** (hero/renders) o **blanco** (boards de concepto), o
  si conviven como dos modos del mismo sistema (recomendado).
- El collage pop es potente pero puede chocar con lo minimalista: usarlo solo como "break".

## Detalles de diseño
- **Colores / paleta:** Negro `#0A0A0B` · Blanco `#F5F4F1` · Naranja acento `#E85D2A` ·
  gradientes aurora fluor (rosa/azul/lila/lima/durazno) para fondos hero.
- **Tipografía:** grotesca bold protagonista (tipo Art Grotesk / Helvetica), versales para
  títulos, itálica de acento, mono para datos/specs.
- **Composición / encuadre:** título grande, subtítulo fino con guiones, slides numeradas,
  texto vertical, full-bleed para imagen/render, mockups de dispositivos.
- **Ritmo / motion:** reveal blur→foco, parallax al scroll, sliders de peso variable,
  repetición rotando. Un "wow" por pantalla, suave.
- **Copy / caption:** títulos cortos y grandes; concepto fuerte (transformation, color change,
  material + technology).

## Cómo está hecho (técnico)
Sitio web con tipografía variable (variable fonts), gradientes animados (CSS/canvas/WebGL),
scroll-triggered reveals y parallax. Los boards son piezas de deck (layout editorial) que se
pueden armar en HTML o en herramienta de diseño. Todo replicable en una plantilla web propia.

## Recomendaciones para aplicar
- Bajar todo a **un sistema dual** (modo negro hero + modo blanco editorial) con naranja de
  acento y aurora para momentos clave. Ver `PERFIL-DE-GUSTOS.md`.
- Para la presentación de renders: negro full-bleed + título grotesca gigante + contador de
  escena + transición aurora entre ambientes.
- Para la marca/IG: alternar posters de tipo (negro) con boards numerados de concepto/material
  (blanco), naranja de hilo conductor.

## Dudas abiertas para revisar
- ¿El concepto de marca va por "arquitectura + tecnología/renders", o querés el formato de
  deck de transformación con TU concepto propio?
- ¿Naranja como único acento, o sumamos la aurora como segundo recurso de color?
- ¿La fuente hero: grotesca tipo Art Grotesk / Helvetica, o buscamos una variable propia?
