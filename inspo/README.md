# Inspo IG — Reportes de inspiración y dudas

Acá se guardan los reportes de inspiración y las dudas sobre publicaciones de
Instagram. El flujo es el mismo que usamos con los videos:

1. **Vos me pasás el material** en la sesión de Claude:
   - Capturas de posts, reels o stories (lo ideal, porque los links de IG
     no se pueden abrir sin login).
   - O el texto / caption / la duda puntual.
2. **Yo lo analizo** (composición, colores, tipografía, estilo, ritmo, qué
   funciona y qué no) y armo el reporte.
3. **Se guarda acá** como archivo con fecha, y se hace commit + push.
   Vos lo bajás con `git pull` en tu compu.

## Convención de nombres

Un archivo por reporte:

```
inspo/2026-07-21-<tema-corto>.md
```

Ejemplo: `inspo/2026-07-21-reels-transiciones.md`

## Plantilla

Usar `_plantilla.md` como base para cada reporte nuevo.
