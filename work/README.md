# work/: mesa de trabajo de FUGA

```
work/
├── _entrada/     ← tirá acá TODO lo que no está en Drive, sin ordenar
├── fuga-tech/    ← código de FUGA Tech (Python + LISP)
│   ├── fuga/     ← paquete Python (kml, geo, lisp, motor, tecmont, autocad…)
│   └── lisp/     ← rutinas AutoCAD sueltas (TEC_LAMINAS.lsp…)
├── marca/        ← textos de marca, voz, copies de posts, decisiones de diseño
├── clientes/     ← una nota por cliente (HTE, Tecmont, arquitectura…)
└── notas/        ← ideas, planes, pendientes, audios transcriptos
```

## Cómo traer lo que falta
1. **Archivos** (código, txt, notas, planillas chicas): subilos a `work/_entrada/`.
   Desde el celu o la web de GitHub: *Add file → Upload files* en esa carpeta.
   Yo los ordeno después.
2. **Lo que está en tu cabeza**: mandalo por el chat, en texto o en audio transcripto,
   aunque sea desordenado. Yo lo paso a `notas/` y al `CLAUDE.md`.
3. **Pesado** (DWG, KMZ, renders, videos, zips): no va al repo. Subilo a Drive
   y decime el nombre de la carpeta.

Qué necesito sí o sí: ver la sección *Pendientes* de `/CLAUDE.md`.
